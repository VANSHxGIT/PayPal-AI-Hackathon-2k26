# Hackathon Compliance Rules

To ensure Evidentia is eligible for the $69,750 prize pool, all development must strictly adhere to the following checklist:

## 1. Mandatory Technical Integrations
- [ ] Meaningful use of a PayPal API (Disputes API & Webhooks).
- [ ] Meaningful use of AI (LLM Evidence Synthesis & RAG).
- [ ] Must use the free PayPal Sandbox environment (no live money/data).

## 2. Repository Requirements
- [ ] Code must be hosted on a public GitHub, GitLab, or Bitbucket repository.
- [ ] Repository must contain an Open Source License file (e.g., MIT, Apache 2.0).
- [ ] A comprehensive `README.md` must be present with step-by-step build/run instructions.

## 3. Video Presentation
- [ ] Video MUST be under 3 minutes (03:00).
- [ ] Must be hosted on YouTube and set to Public or Unlisted.
- [ ] Must show the project functioning (live demo of the Sandbox webhook firing and the AI reacting).
- [ ] NO copyrighted music or third-party trademarks without permission.

## 4. Sponsor Tools
- [ ] Explicitly document the use of AG Grid, Elastic, and Render in the Devpost submission and `README.md`.
